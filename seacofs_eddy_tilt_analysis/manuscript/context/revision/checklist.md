# Coordinated manuscript revision

Status: organisation complete; scientific/editorial audit pending. This is the
single working checklist for the main paper, supplement and supervisor feedback.
Repository locations and starting revisions: [resources.md](../resources.md).

## Working rules

Describe the dataset-producing code/configuration in the supplement. Check
provenance rather than assuming current public code and the local producing
version are identical. Align the main paper with agreed analyses and current
outputs. Bring substantive code/text discrepancies and proposed structural
changes back for discussion before implementation.

Read comments and tracked changes before revising; do not automatically apply
either. Preserve original exports and backups. Editing branches, compilation,
merging and Overleaf synchronisation belong to the later agreed editing stage.

## Read-only review

- [ ] Confirm paper/supplement revisions and match supervisor anchors to the paper.
- [ ] Record/locate the original source ZIP and verify the recovery baseline.
- [ ] Establish dataset-producing pipeline/config/ESP versions and compare with public code.
- [ ] Check supplement descriptions against detection, fitting, QC, tracking,
      processing, vertical reconstruction and tilt code/settings.
- [ ] Check main-paper methods, results, captions and claims against current topic reports/tables.
- [ ] Check shared terminology, units, coordinates, thresholds, depth support,
      temporal treatment, weighting and uncertainty across both manuscripts.
- [ ] Propose a concise paper/supplement structure, including what to move or shorten.
- [ ] Agree the discrepancy resolutions and revision scope before editing either text.
