# Original manuscript backups

The user reports saving the original Overleaf manuscript to GitHub and downloading
the source ZIP before revision. Repository recovery references are recorded in
[resources.md](../resources.md).

No original ZIP or PDF is currently stored in this folder. Its download location
is not established here. When a snapshot is placed here, retain it unchanged and
record its original filename, date and corresponding manuscript revision below.
Do not assume a source ZIP or compiled PDF includes sidebar comments; those are
preserved separately under [reviews/](../reviews/overleaf-comments/).
